Trial and Registration

The 30-day trial

DX Atlas Pro works for 30 days after the first start with no function disabled or limited. The days left are shown in the Help > About box, as Trial version: N days left.

When the trial ends, the program shows the message Your 30-day trial of DX Atlas Pro has ended at startup, with two buttons:

  • Get Registration Key opens the Register page, where the key is sold;
  • Enter Registration Key opens the dialog where you paste the key you have received.

The program does not start until a valid key is entered. Closing the message ends the program.

Buying a key

A registration key is issued to one person by name and registers all 1.xx versions of DX Atlas Pro. To buy one, click Help > Get Registration Key, or open the Register page, and click Buy now.

At checkout, type the name the key should be issued to - your name or your callsign - in the registration name field; if you leave it empty, the key is issued to your billing name. The store emails you the key right after the purchase.

Entering the key

  1. Copy the whole key from the email: it takes several lines;
  2. in DX Atlas Pro, click Help > Enter Registration Key, or click Enter Registration Key in the message shown when the trial has ended;
  3. paste the key where the dialog says Paste the registration key from your email, and click OK.

The program then shows Thank you for registering DX Atlas Pro. Licensed to ‹name›. The name is also shown in the main window's title, DX Atlas Pro v.X.Y - registered to ‹name›, and in the Help > About box. Once a key is entered, Get Registration Key and Enter Registration Key are disabled in the Help menu.

The key is checked on your computer: the program never contacts a server to check it. You may use the key on any computer you use; enter it on each one.

If the key is not accepted

The dialog says why:

  • This is not a registration key - only part of the key was pasted, or other text with it. Copy the key's lines again, without the text around them;
  • This registration key is not valid - the key was changed, for example a character was lost when it was copied;
  • This registration key has been revoked - the key's order was refunded or the key was misused.

For any other problem, write to support@dxatlas.com.
