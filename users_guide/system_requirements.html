System Requirements

Hardware

  • Computer: 64-bit PC with an x64 processor;
  • Video Card: on Windows, any video card with a Direct3D 11 driver; on Linux, OpenGL 3.3 or higher;
  • Disk Space: about 200 MB;
  • Internet: optional. Without it, the program works fully as an atlas; the connection is used to download the sunspot number and the Ap index for the ionospheric and propagation maps, and the auroral oval in real time.

Software

  • Windows: Windows 10 or Windows 11, 64-bit. The setup program installs the .NET 10 Runtime and the Microsoft Visual C++ Redistributable if they are not on the computer yet;
  • Linux: 64-bit x64 Linux with an X11 desktop and an OpenGL driver. The program is self-contained and needs no .NET Runtime. Tested on Ubuntu 24.04.
