### Release Notes

#### v.1.4

- the new Propagation Chart dialog, opened from the map menu, shows hourly propagation on all bands for a single path
- the new Space Weather panel in the lower right corner of the map shows the SFI, Kp index, solar wind speed and Bz from NOAA SWPC
- the Lists panel now shows a count bar
- the ten pin colours can now be edited in the Colors dialog

#### v.1.3

- the destination marker (antenna) via [DXView](https://www.dxlabsuite.com/dxview/) automation is drawn on both maps
- new hint style for via [DXView](https://www.dxlabsuite.com/dxview/) spots
- truncated tooltips for user layers fixed
- red dots not drawn via [DXView](https://www.dxlabsuite.com/dxview/) automation fixed
- Show Details dialog has a propagation row
- the Lists panel shows details only for selected item, not for its parents
- city labels drawing changed, to make capitals and big cities more visible
- capitals and state/province centers are shown as stars and diamonds respectively
- country names are in a larger font

#### v.1.2

- a left click freezes the great circle path, another click releases it
- the list menu has a Check All command
- the COM bridge draws on both maps
- new default label fonts

#### v.1.1

- great circle path on both maps, long path in red
- Readout tooltip: azimuth, distance and the reading under the pointer
- DXView: the window comes to the front, DXView's lines are shown

#### v.1.0

- first stable release, with all defects reported during beta testing fixed

#### v.0.92 Beta

- WAP list updated

#### v.0.91 Beta

- WAP list of Antarctic bases added

#### v.0.9 Beta

- first public beta
